# Сайт

Документация по сайту DevCraft Club и связанным сервисам.

## Разделы

- [Как попросить поддержку](how-to-ask-for-support.md) - Инструкция по обращению за поддержкой
- [Как купить](how-to-buy.md) - Инструкция по покупке платных разработок

## О сайте

Этот сайт построен на React и системе Docusaurus. Все исходные коды доступны на [GitHub](https://github.com/DevCraftClub/mhdocs).

### Технологии

- **Frontend**: React, Docusaurus
- **Стили**: CSS, SCSS
- **Язык**: TypeScript
- **Хостинг**: GitHub Pages

### Структура

- `/docs` - Основная документация
- `/docs/dev` - Документация по разработкам
- `/docs/site` - Документация по сайту
- `/blog` - Блог с новостями и обновлениями
