# Добро пожаловать в DevCraft Документации

Сайт с документациями, который построен на React и системе Docusaurus. Исходники всегда будут доступны на GitHub.

## 🚀 Быстрый старт

Выберите раздел документации, который вас интересует:

- **[Разработки](/docs/dev)** - Все наши проекты и инструменты
- **[Сайт](/docs/site)** - Документация по сайту

## 📚 Основные разделы

### Разработки

В разделе [Разработки](/docs/dev) вы найдете:

- **Инструкции** - Руководства по установке и настройке
- **API Wrappers** - Библиотеки для работы с внешними API
- **Бесплатные разработки** - Открытые проекты
- **Платные разработки** - Коммерческие модули
- **Инструменты и утилиты** - Вспомогательные программы

### Сайт

В разделе [Сайт](/docs/site) вы найдете:

- Инструкции по обращению за поддержкой
- Информацию о покупке платных разработок
- Техническую документацию по сайту

## 🔧 Технологии

- **Frontend**: React, Docusaurus
- **Стили**: CSS, SCSS
- **Язык**: TypeScript
- **Хостинг**: GitHub Pages
