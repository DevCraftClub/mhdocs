# Настройка

Административная панель DevCraft Admin построена на [Metro UI](https://github.com/olton/metroui). Глобальные настройки задаются на странице **Настройки** и описаны в `devcraft/src/modules/Admin/settings.schema.php`.

![Настройки](./assets/settings.png)

## Общие

| Настройка | Описание | Тип |
|-----------|----------|-----|
| Количество объектов (`list_count`) | Количество элементов в списках и таблицах для всех модулей автора. При пустом значении используется настройка DLE «Количество отображаемых новостей на страницу». | Число |
| Время хранения кеша (`cache_timer`) | Время жизни файлового кеша в минутах. По умолчанию: **60**. | Число |
| Язык админки (`language`) | Локаль интерфейса (например, `ru_RU`). | Список |
| Тема оформления (`theme`) | Светлая (`light`) или тёмная (`dark`). После смены сохраните настройки и обновите страницу. | Список |

## Отладка

| Настройка | Описание | Тип |
|-----------|----------|-----|
| Режим отладки (`debug`) | Подробные сообщения в консоль браузера, `error_log` и журнал (тип `debug`). Для разовой проверки без сохранения: `?dc_debug=1` в URL админки. | Переключатель |

## Пути

| Настройка | Описание | Тип |
|-----------|----------|-----|
| Путь до кеша (`cache_path`) | Каталог файлового кеша относительно корня сайта. По умолчанию: `devcraft/cache/`. | Текст |
| Путь до языков (`locales_path`) | Каталог XLIFF/локалей. По умолчанию: `devcraft/locales/`. | Текст |

## Логирование

| Настройка | Описание | Тип |
|-----------|----------|-----|
| Включить логирование (`logs`) | Текстовые логи в каталоге `devcraft/logs/`. | Переключатель |
| Сохранять в БД (`logs_db`) | Дублирование записей в таблицу логов. | Переключатель |
| Telegram (`logs_telegram`) | Отправка логов в канал при заполненных полях ниже. | Переключатель |
| API ключ бота (`logs_telegram_api`) | Токен от [@BotFather](https://t.me/BotFather) (`/newbot` или `/mybots` → API Token). Пошагово для каналов: [Re: Post → Telegram](../../repost/providers/telegram.md). | Текст |
| Канал (`logs_telegram_channel`) | ID канала Telegram. | Текст |
| Тип сохраняемых логов (`logs_save_types`) | Фильтр типов для file / БД / Telegram: все, ошибки, info, notice, warning, critical, debug. При «Все» остальные игнорируются. При включённом debug сохраняются все типы. | Множественный выбор |

## Проверка целостности файлов

Раз в сутки выполняется автоматическая проверка ассетов модуля. При расхождениях в шапке админки отображается индикатор; подробности — в диалоге синхронизации (см. класс `AssetsCheckerService` в [справочнике API](../reference/back-end/classes/AssetsCheckerService.md)).
