# Генератор пользователей

Страница: `?mod=dle_faker&action=generator-users`.

Задайте число пользователей, группу, шаблоны полей и (при наличии) доп. поля профиля. Запросы — `generate_users` через `devcraft/ajax.php`. Созданные user_id могут попадать в пул настроек модуля.
