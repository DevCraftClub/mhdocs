Настройки пользователя v200.1.0

Как права группы, доп. поля профиля и галочки DLE отсекают каналы

Даже при включённом модуле канал может отсечься настройками человека. Проверки идут сверху вниз; первый отказ останавливает этот канал.

  1. Права группы — действие разрешено.
  2. Общий выключатель (необязательное доп. поле) — уведомления не отключены целиком.
  3. Доп. поле по классу событий — не отключён класс (новости, упоминания, …).
  4. Почта и профиль DLE:
    • «Подписка на ответы в комментариях» → событие ответа;
    • «Подписка на комментарии к новостям» → комментарий к своей статье.
  5. Глобальные каналы модуля — почта / личные сообщения включены в настройках.

Лента на сайте и личные сообщения не зависят от news_subscribe / comments_reply_subscribe: эти флаги DLE относятся только к почте.
