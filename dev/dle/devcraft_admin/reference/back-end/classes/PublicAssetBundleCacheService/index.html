Класс: PublicAssetBundleCacheService v200.4.1

Кэш объединённых CSS/JS бандлов оболочки.

Описание: Собирает объединённые bundle.css / bundle.js в devcraft/cache/public_assets/ и пишет туда .htaccess с доступом (родительский devcraft/.htaccess иначе отдаёт 403).

Namespace: DevCraft\Modules\Admin\Services

С версии: 200.4.1

См. также:

  • Гайд: Публичные ресурсы оболочки
  • ModuleSiteAssets
  • PublicAssetTagService

Путь

devcraft/src/modules/Admin/Services/PublicAssetBundleCacheService.php

Методы

ensureCacheDir(): ?string

Создаёт каталог кэша и при отсутствии файла — .htaccess с Require all granted. Возвращает путь к каталогу или null, если каталог не удалось создать.

ensure(string $kind): ?string

Собирает или переиспользует бандл css / js. Перед записью вызывает ensureCacheDir().

invalidate(string $kind): void

Удаляет файл бандла и его meta для указанного вида.
