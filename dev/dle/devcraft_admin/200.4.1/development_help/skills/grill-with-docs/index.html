Grill with docs

Уточнение терминов и ADR перед спекой — mattpocock/skills grill-with-docs.

Канон: mattpocock/skills — grill-with-docs. Тянет grilling + domain-modeling. Не авто-invoke на каждую мелочь.

Workflow для DevCraft

  1. Прояснить термины: mod / code, сателлит, Page vs Ajax → glossary.
  2. Жёсткие решения → ADR (только если skill требует; Constitution XI — не плодить docs без нужды).
  3. Затем implement по create-devcraft-plugin.

Внутри create-devcraft-plugin: при пробелах — 1–2 вопроса за раунд, простым языком.
