InvalidArgument v1.1.0

PSR-6 InvalidArgumentException для невалидного ключа кэша.

Описание: Расширяет \InvalidArgumentException и реализует Psr\Cache\InvalidArgumentException. Бросается FileCachePool при пустом/слишком длинном ключе, reserved-символах ({}()\@:) или .. в ключе.

Namespace: Devcraft\Exceptions

С версии: 1.1.0

См. также:

  • FileCachePool
  • Гайд: файловый PSR-6 кэш
