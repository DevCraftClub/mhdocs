СправочникВалидация

PropertyValidator v1.0.1

Запуск ValidationRule-атрибутов на свойстве или объекте без гидратации.

Описание: Утилита валидации: читает атрибуты свойства, инстанцирует ValidationRule, собирает сообщения. Используется ReflectionMapper и может вызываться отдельно.

Namespace: Devcraft\Validation

С версии: 1.0.0

См. также:

  • ValidationRule
  • ReflectionMapper
  • Гайд: валидация

Методы

validateValue(ReflectionProperty $property, mixed $value): array

Описание: Возвращает list<string> сообщений для одного свойства. Атрибуты не из ValidationRule игнорируются.

Параметры:

ПараметрТипОписание
$propertyReflectionPropertyСвойство с атрибутами-правилами
$valuemixedПроверяемое значение

Возвращает: array — list<string> сообщений

validateObject(object $object): array

Описание: Возвращает array<string, list<string>> по имени свойства. Смотрит только public, non-static, initialized свойства.

Параметры:

ПараметрТипОписание
$objectobjectЭкземпляр для проверки

Возвращает: array — карта ошибок по имени свойства

ReflectionMapper

Гидратация и сериализация public-свойств DTO с валидацией.

ReflectionInterface

Контракт DTO: fromArray, toArray, toJson.
